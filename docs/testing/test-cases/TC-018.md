# TC-018

- **ID:** TC-018
- **Title:** Verify that a displayed error is removed and the success message appears after the input is corrected.
- **Requirement / user story reference:** REQ-007, US-005, AC-016
- **Type:** Regression
- **Priority:** Medium
- **Preconditions:** `index.html` is open in Chromium; all fields are empty.
- **Test data:** Name: `Anna Svensson`; Email: `anna@example.com`; Password: `password123`; Age: first `17`, then `30`
- **Steps:**
  1. Enter the Name, Email and Password values and `17` in `age-input`.
  2. Click `submit-button` and confirm that `error-age` is displayed.
  3. Replace the Age value with `30`.
  4. Click `submit-button` again.
- **Expected result:** At step 2 `error-age` is visible. At step 4 `error-list` is not visible and `success-message` is visible.
- **Actual result:** Failed at step 2. `error-age` was not displayed for Age 17 (element not found after the 5 s timeout), so steps 3 and 4 were not reached. The failure is caused by the Age 17 behavior seen in TC-011 (BUG-001); the reset behavior itself is therefore not yet verified. The test data should be reviewed so this case does not depend on a value affected by another defect.
- **Status:** Fail
- **Automation:** Automated, `tests/e2e/registration.spec.ts` › Form-level behavior › errors are cleared and success shown after correcting the input. Executed 2026-10-22.
