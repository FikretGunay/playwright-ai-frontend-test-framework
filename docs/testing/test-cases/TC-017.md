# TC-017

- **ID:** TC-017
- **Title:** Verify that submitting an empty form lists four required errors.
- **Requirement / user story reference:** REQ-005, US-005, AC-015
- **Type:** Functional
- **Priority:** High
- **Preconditions:** `index.html` is open in Chromium; all fields are empty.
- **Test data:** All fields empty.
- **Steps:**
  1. Click `submit-button` without entering any data.
- **Expected result:** `error-list` contains exactly four entries in this order: `Name is required.`, `Email is required.`, `Password is required.`, `Age is required.`; `success-message` is not visible.
- **Actual result:** As expected. Error list contained the four entries with the expected texts in the expected order; success message hidden. (The first execution only counted the entries; the automated test was then extended to assert text and order and rerun.)
- **Status:** Pass
- **Automation:** Automated, `tests/e2e/registration.spec.ts` › Form-level behavior › all fields empty shows four required errors. Executed 2026-10-22.
